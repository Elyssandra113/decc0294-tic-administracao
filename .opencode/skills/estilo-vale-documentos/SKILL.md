# Estilo Vale para Criação de Documentos

Proposta de padrao inspirada na identidade pública da Vale. NAO é o manual oficial de marca. Validar cores e logo no manual oficial antes de entrega externa.

## 1. Quando usar
- Relatórios, propostas, atas e ofícios que precisam sair com cara de documento corporativo Vale.
- Não usar para chat informal, código ou rascunho rápido.

## 2. Estrutura obrigatória
1. Capa: título, subtítulo, data dd/mm/aaaa, autor/área, classificação (Interno/Restrito se houver)
2. Sumário (se >3 páginas)
3. Objetivo em até 5 linhas
4. Desenvolvimento: passo a passo numerado
5. Interpretação + Limitação declarada
6. Anexos / Fontes com origem de cada número

## 3. Visual
- Fonte: Arial ou Calibri, corpo 11, títulos 14/12 em negrito
- Cores base: verde Vale e azul petróleo + cinza para tabelas. NAO SEI os hex oficiais — confirmar no brandbook.
- Margens 2,5cm, espaçamento 1,15, páginas numeradas
- Tabelas: cabeçalho escuro, linhas alternadas, fonte de cada dado no rodapé
- Logo Vale só na capa e com área de respiro. Não esticar, não mudar cor.

## 4. Tom de escrita
- Objetivo, direto, sem gíria em documento externo
- Frases curtas. Voz ativa.
- Segurança e sustentabilidade sempre explícitas quando houver operação, dado ou impacto.
- Números: sempre com fonte. Ex: "Turnover 12% (Fonte: dados_RH...xlsx, aba Funcionarios)".
- Referências: se não souber, escrever NAO SEI. Nunca inventar autor ou norma.

## 5. Checklist antes de entregar
- [ ] Título, data e autor conferem?
- [ ] Todo número tem fonte?
- [ ] Termos técnicos definidos na 1ª ocorrência?
- [ ] Classificação de sigilo aplicada?
- [ ] Revisão PT-BR sem gíria no texto final?

## 6. Exemplo de abertura
```markdown
# Relatório de Turnover – Filial Campinas/SP
**Objetivo:** Analisar desligamentos do 1º sem/2026 para propor retenção.
**Fonte:** dados_RH_Livraria_Mundo_das_Letras.xlsx, aba Funcionarios
**Limitação:** base de 250 linhas, recorte SP. Não generalizar para BR.
```
